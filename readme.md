# Asana SF Integration — Discovery

Local workspace for inventorying Asana API surface before building the SF-side Apex integration.

## Setup
1. Install VS Code extension: REST Client (humao.rest-client)
2. Get an Asana PAT: https://app.asana.com/0/my-apps
3. Paste PAT into `asana-discovery.http` (do not commit)

## Files
- `asana-discovery.http` — discovery requests for project/field GIDs
